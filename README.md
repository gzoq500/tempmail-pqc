# TempMail PQC Service

Enterprise-grade temporary email web service featuring **ML-KEM-768 (Kyber-768)** Post-Quantum Cryptography, high-performance C++ backend, and modern Svelte frontend.

## Features
- 🛡️ **ML-KEM-768 Post-Quantum Key Encapsulation (PQClean)**
- ⚡ **Ultra-fast C++ 17 Web Server** (cpp-httplib, minimal SQLite)
- 🎨 **Modern Svelte SPA Frontend**
- ☁️ **Cloudflare Inbound Webhook Support**
- 🐳 **Containerized Deployment Ready**
